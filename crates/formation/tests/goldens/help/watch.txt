Run probes on an interval and report or mail new items

Usage: formation watch [OPTIONS] --probe <NAME=COMMAND>

Options:
      --room <NAME|PATH>      Room name or directory path (default: $FORMATION_ROOM or session file)
      --as <SEAT>             Seat name for this command (default: seat recorded for this session)
      --probe <NAME=COMMAND>  Probe to run as <name>=<command>; repeat for multiple probes
      --to <SEAT>             Joined recipient seat to mail new items to instead of returning JSON
      --every <SECONDS>       Seconds between polls (minimum 10) [default: 120]
      --timeout <SECONDS>     Seconds to run before exiting (default: 300 without --to, none with --to)
  -h, --help                  Print help
