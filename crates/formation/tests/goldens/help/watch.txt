Manage the room's watches and wait for probe results

Usage: formation watch [OPTIONS] <COMMAND>

Commands:
  add     Add a watch to the room's set, or replace the one with the same name and recipient
  remove  Drop a watch and forget its remembered fingerprints
  pause   Keep a watch but stop reading it
  resume  Read a paused watch again
  list    List every watch in the room and whether anything reads the set
  run     Read the room's watches, or wait as a standby while another reader holds the lease
  stop    Stop the room's reader and all its standbys
  wait    Block until a caller-supplied probe returns new items or a read failure
  help    Print this message or the help of the given subcommand(s)

Options:
      --room <NAME|PATH>  Room name or directory path (default: $FORMATION_ROOM or session file)
      --as <SEAT>         Seat name for this command (default: seat recorded for this session)
  -h, --help              Print help
