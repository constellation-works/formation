Pass a request you hold to your parent, or to the admiral if you have no parent

Usage: formation request pass [OPTIONS] <REQUEST>

Arguments:
  <REQUEST>  Request identifier

Options:
      --recommend <LABEL>  Label of the option you recommend
      --room <NAME|PATH>   Room name or directory path (default: $FORMATION_ROOM or session file)
      --as <SEAT>          Joined seat to act as (default: session seat; terminal settle and reopen use admiral)
      --note <TEXT>        Explain the recommendation supplied with --recommend
      --json               Print machine-readable JSON
  -h, --help               Print help
