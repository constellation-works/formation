Exchange messages in a private local room

Usage: formation mail [OPTIONS] <COMMAND>

Commands:
  join   Register this seat or refresh its presence
  who    List seats seen in the last 90 seconds
  send   Send to an online seat. Reuse the ID when retrying
  inbox  Read unread messages or wait for up to 900 seconds
  ack    Mark a receipt in this seat's inbox as handled
  help   Print this message or the help of the given subcommand(s)

Options:
      --room <NAME|PATH>  Room name or directory path (default: $FORMATION_ROOM or session file)
      --as <SEAT>         Seat name for this command (default: seat recorded for this session)
  -h, --help              Print help
