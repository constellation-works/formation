Add a recommendation without changing the request's state or holder

Usage: formation request advise [OPTIONS] --recommend <LABEL> --note <TEXT> <REQUEST>

Arguments:
  <REQUEST>  Request identifier

Options:
      --recommend <LABEL>  Label of the option you recommend
      --room <NAME|PATH>   Room name or directory path (default: $FORMATION_ROOM or session file)
      --as <SEAT>          Joined seat to act as (default: this session's seat)
      --note <TEXT>        Explain the recommendation
      --json               Print machine-readable JSON
  -h, --help               Print help
