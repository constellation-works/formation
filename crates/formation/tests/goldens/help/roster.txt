Inspect a shift roster

Usage: formation roster <COMMAND>

Commands:
  check  Validate one version 1 or 2 JSON roster on stdin (maximum 256 KiB)
  show   Show a room's roster and seat presence
  apply  Apply a version 2 JSON roster to an existing room
  list   List rooms in the Formation home, newest first
  close  Record the room's close as the joined seat
  help   Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
