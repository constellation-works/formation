List room mail, newest first

Usage: formation mail log [OPTIONS]

Options:
      --room <NAME|PATH>  Room name or directory path (default: $FORMATION_ROOM or session file)
      --seat <SEAT>       Include envelopes sent or received by this seat
      --as <SEAT>         Seat name for this command (default: seat recorded for this session, or admiral at a terminal)
      --with <WITH>       Include envelopes involving this other seat
      --json              Print JSON, overriding $FORMATION_FORMAT (auto, human or json)
      --since <SINCE>     Include envelopes stored at or after this RFC 3339 timestamp
      --limit <LIMIT>     Maximum number of envelopes or threads [default: 50]
      --no-watch          Exclude envelopes produced by watches
      --full              Print whole bodies
      --threads           Group envelopes linked by a reply or a request
  -h, --help              Print help
