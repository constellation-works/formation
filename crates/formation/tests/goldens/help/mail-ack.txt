Mark a receipt in this seat's inbox as handled

Usage: formation mail ack [OPTIONS] <RECEIPT>

Arguments:
  <RECEIPT>  Numeric receipt from the inbox

Options:
      --room <NAME|PATH>  Room name or directory path (default: $FORMATION_ROOM or session file)
      --as <SEAT>         Seat name for this command (default: seat recorded for this session)
  -h, --help              Print help
