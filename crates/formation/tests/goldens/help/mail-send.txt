Send to a joined seat, present or not. Reuse the ID when retrying

Usage: formation mail send [OPTIONS] --id <ID> --body <BODY> <TO>

Arguments:
  <TO>  Joined recipient seat name

Options:
      --id <ID>           Caller-generated message identifier
      --room <NAME|PATH>  Room name or directory path (default: $FORMATION_ROOM or session file)
      --as <SEAT>         Seat name for this command (default: seat recorded for this session, or admiral at a terminal)
      --body <BODY>       Message text (up to 8192 bytes)
      --json              Print JSON, overriding $FORMATION_FORMAT (auto, human or json)
      --re <RECEIPT>      Reply to a receipt from your mail log
  -h, --help              Print help
