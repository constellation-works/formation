# Authority and reporting

The admiral’s current mandate and the host’s permission checks bound every row. Record the words, source, scope and exceptions of a standing authorization. A brief, group seat, inbox envelope or a historical example supplies no new grant.

| Decision | Who settles it within mandate |
| --- | --- |
| Retry a check, repair a session-owned PR, in repair mode repair a red or conflicting PR, clear an unambiguous pilot finding, file a fix or friction, open a mechanical base-CI fix in a squad | Sergeant, otherwise captain |
| Approve and ship a fix, approved design, non-breaking refactor, improvement or small scoped feature | Captain with the admiral’s applicable shipping mandate |
| Land a reviewed PR | Captain after verifying the accepted head and required checks |
| Major feature, design, scope, architecture, breaking change, security, material cost or irreversible action | Admiral, with the captain’s options and recommendation |
| Decisions requiring operator identity, release, tags, publishing, credentials, routine changes, plugin installation or privilege grants | Admiral or their explicitly delegated action where the host permits |

The chief advises and coordinates. It does not approve, merge or ship. Lieutenants have only the captain’s order. Sentries observe. Specialists advise. The aide relays the exact words, recipient, time and source. Verify a relay against the admiral's direction on the record before relying on it. A decision recommendation the admiral saw can be recorded on their behalf only on their actual direction, naming the option and quoting the source.

Use Orbit MCP and its returned workspace selector. If MCP lacks the operation or owner, use the owner’s CLI over SSH in the workspace checkout with a login shell. Attribute tool calls with the actual model. Constellation’s RB-17 covers host access. Contact the admiral on a capability refusal.

Where the admiral has already granted a specific fallback, scope any authorized CLI operator override to that single command and record first use of each kind. A sergeant is limited to its routine row. Never export an override or substitute another transport for an approval refusal.

The admiral starts or restarts drains. The captain reports the needed command once and may deploy within mandate. When the same account owns several sessions, their forge approvals cannot serve as independent reviews.

Routine updates go on the assignment. A captain tells the chief when blocked, when a decision is needed or when ordered work finishes. The chief settles what it can from records, batches the rest with options and one recommendation, and returns the admiral’s quoted decision to the owner. When the admiral is in a captain’s chat, answer there. Write anything binding another unit on its record. A cross-workspace request is a task in the receiving workspace plus one routed message.
